# Правила доработки форм 1С

Перед добавлением поля на форму списка:

1. Найти файл формы списка.
2. Определить тип формы: обычная или управляемая.
3. Найти модуль формы.
4. Найти источник данных списка.
5. Проверить, есть ли нужное поле в объекте, запросе или реквизитах формы.
6. Если поле нужно вычислять, определить правильное место:
   - запрос динамического списка;
   - обработчик ПриВыводеСтроки;
   - временная таблица;
   - реквизит формы;
   - отдельный запрос при открытии формы.
7. Не предлагать несуществующие свойства формы.
8. Не использовать методы управляемых форм для обычных форм.
9. Не использовать методы обычных форм для управляемых форм.
10. Все изменения сверять с похожими формами в этой конфигурации.
